## 用語の候補（2026-08-20。確定したら `03` の「1. 用語」へ）

**危ない語が 3 つあった：**「キャンセル」（3 つの別物を指す）、「削除」（消えないものまで消えると読める）、「廃棄」（物理の作業と記録が混ざる）。

| 呼称（これで統一） | 何を指すか | 使わない・言い換えない |
|---|---|---|
| 差し戻し | 薬局が不備を理由に、送信を患者へ返すこと（理由 6 つ・毎回記録） | キャンセル、却下、返却 |
| 取り消し | 調剤開始の前に、患者（またはスタッフ代行）が送信をやめること | キャンセル |
| 未来店 | 受け取り時間を過ぎても来店していない状態（期限内なら復帰がある） | キャンセル、無断キャンセル |
| 期限切れ終了 | 差し戻されたまま期限が過ぎ、閉店時に閉じたこと | 自動キャンセル |
| 取り置き終了 | 14 日の取り置きを終えたこと。棚戻し／廃棄は現場の作業で、記録に残る語はこれだけ | 廃棄 |
| 登録解除 | アカウント・患者を新規に使えなくすること。過去の記録は氏名ごと残る | 削除、退会 |
| 削除 | **画像の 90 日自動削除にだけ使う**──本当に消えるのはこれだけ | — |

**「キャンセル」という語そのものを使わない**（差し戻し・取り消し・未来店の 3 つを区別できなくなるため）。
