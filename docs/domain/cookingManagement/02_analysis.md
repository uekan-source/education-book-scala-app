**名詞**：
会員、店舗スタッフ、店舗、タブレット、メニュー、商品、材料、

**動詞**：
注文する、支払う、見る、並べ替える、選ぶ、
調理を開始する、できあがりにする、渡す、受渡し完了にする、
未受け取りにする、売り切れにする、切れる、
進める、飛ばす、戻す、変える、影響する、続行する
| 種類 | 動詞 | 行き先 |
|---|---|---|
|状態を変える|調理を開始する|Order.Statusの遷移（受付 → 調理中）|
|状態を変える|できあがりにする|Order.Statusの遷移（調理中 → 受取準備完了）|
|状態を変える|受け渡し完了にする|Order.Statusの遷移（受取準備完了 → 受渡し完了）|

|値を変える|受け取り時間の近い順に並び替える|モデルのメソッド|
