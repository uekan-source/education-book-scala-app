# 店舗スタッフ向けの調理管理 — 要件定義

## 受け取った要求
「店舗のタブレットで、入った注文を見られるようにしたい。 『調理中』『できあがり』を押していく。 混んでいるときは、受け取り時間の近いものから作りたい。 急に材料が切れたら、その場で商品を売り切れにしたい。 お客さんが来なかった注文は、閉店時に一括で『未受け取り』として片付けたい。」

## 確認したいこと（質問リスト）
| 質問 | 今回の回答（仮） |
|---|---|
|売り切れにする操作に権限は必要か|店舗の誰でも操作可能|
|カートにメニューを入れた後に売り切れになった場合はどうなるか|支払う前であればカートから除外される|
|混んでいる時の基準はどうするか|調理中のステータスが同時に5つになったらにする|



## 業務フロー
```
[会員]
1. メニューを見て注文をする

[店舗スタッフ]
2. 店舗のタブレットで入った注文を確認する
3. 調理中のボタンを押して、調理を開始する
4. 出来上がったら出来上がりのボタンを押す
5. お客さんが来なかった注文は、閉店時にまとめて未受取として扱う

[例外・ルール]
- 材料が切れていたらそのメニューは注文できない
- 売り切れにする操作は店舗スタッフの誰でも操作可能
- カートに入れた後にメニューが売り切れていた場合は支払う前にアラートを出す
- 混んでいる時の基準は調理中のステータスが当時に5つになったらする
