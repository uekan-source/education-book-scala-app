# 問題1：スタンプカード（ポイント） - 思考過程(メモ・提出しない)


##  名詞と動詞

**名詞**：会員、店舗、注文、注文明細、支払い、スタンプ、有効期限、クーポン

**動詞**：ログインする、確認する、支払う、キャンセルする、
      (スタンプが)付与される、(クーポンを)使う、

##  ふるい分け
  （エンティティ / 値オブジェクト / ただの属性 / 対象外）

   | 名詞 | 仕分け | 理由 |
   | ---  | --- | --- |
   | 会員 | エンティティ | ID で区別する。雛形の User をそのまま使う |
   | 店舗 | エンティティ | 複数あり、それぞれ独立して管理される |
   | 注文 | エンティティ | 業務の中心。ID で追跡し、履歴として残す |
   | 注文明細 | **エンティティ** | 1 注文に複数。1 行ごとに商品・数量・価格を持つ |
   | 支払い | **エンティティ** | 外部サービスの取引 ID と結果を記録し、追跡する |
   | スタンプ | エンティティ | 有効期限があり履歴を追わないといけないため |
   | 有効期限 | 値オブジェクト | スタンプの一部 |
   | クーポン | 値オブジェクト | 個数で決まる
