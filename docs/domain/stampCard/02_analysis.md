## 問題1：スタンプカード（ポイント）


### 1. 業務フロー（主語つき・例外つき）

```
[会員]
 1. アプリを開き、ログインする
 2. 会員メニューでスタンプ数を確認できる(有効期限も確認できる)
 3. クーポンを使用するか選ぶ(スタンプ10個貯まっていた場合)
 4. 支払いが終わって、スタンプが一つ付与される

[システム]
 5. 支払いが終わったら、スタンプを付与する
 6. 支払い後にキャンセルがあったら、スタンプが取り消しになる

[例外・ルール]
 - 注文がキャンセルされたらスタンプは付与されない
 - 1年過ぎたら1個ごとに期限切れ判定を行う
 - スタンプは店舗をまたいで共通
 ```

### 2. 名詞と動詞の一覧

**名詞**：会員、店舗、注文、注文明細、支払い、スタンプ、有効期限、クーポン

**動詞**：ログインする、確認する、支払う、キャンセルする、
      (スタンプが)付与される、(クーポンを)使う、

### 6. 判断の記録（迷ったところと、その決着。02_BURGER_DOMAIN の「設計上の論点」と同じ形式で）
#### 「いま何個たまっているか」を数値として保存するか、押した記録（履歴）から数え上げるか。 どちらにも利点と欠点があります。第2部 04章 総合問題1 の「状態と履歴を分ける」を思い出してください。
      押した履歴から数え上げる
      キャンセルで取り消しが起きたり、使用済み10個を区別したりする必要があるから、
      数値1つでは表せない。だから1個ずつの記録（履歴）で持つ
      画面に出す"○個"は、履歴を数え上げて出す（数値としては保存しない）

#### 「10個たまったら無料」の 無料になった1回 は、何として記録されるか。次に見たとき「使用済みの10個」と「たまり始めた新しい1個」を区別できるか。
      無料になった1回はクーポン1つ分としてカウントする
      次に見た時は使用ずみ1個としてカウントし、たまり始めた新しい１個と区別する

#### 有効期限「最後の注文から1年」は、どのタイミングで、どう判定するか。期限切れを表す状態を持つのか、日付から計算するのか。
     日付から計算する
     その注文の日付から１年経ったらそのスタンプは期限切れと判定する

#### 注文がキャンセルされたら、スタンプはどうなるか（要求に書かれていません。あなたの判断と、その理由を書いてください）。
     支払いがあった時点でスタンプは付与して、その後注文キャンセルになったら、
     取り消しをする
     1個ずつ記録で持つから、付与した1個を名指しで"取り消し"として印を付けられる。
     数値を1減らすのではなく、取り消しの記録を残す

#### クーポンをエンティティにするか値オブジェクトして扱うか
     今回の要件では値オブジェクトで足りるため、値オブジェクトにする。
     (有効期限や追跡の必要がないため)
     ただし実務で有効期限や使用先の追跡が必要になることもあるため、必要があれば、
     エンティティに昇格させる
