# スタンプカード（ポイント） — 要件定義

## 受け取った要求
「注文1回につきスタンプを1個押したい。
10個たまったら、次の注文でハンバーガー1つが無料になる。
スタンプは店舗をまたいで共通。有効期限は最後の注文から1年。
お客さんは、いま何個たまっているかをアプリで見たい。」

## 確認したいこと（質問リスト）
| 質問 | 今回の回答（仮） |
|---|---|
|有効期限は「スタンプ1個ごとに付与日から1年（カレンダー上の同日）」か、「カード全体が最後の注文日から1年」か。後者だと1年に1回来店するだけで無期限に維持できてしまい、購買意欲向上に沿わないが、それでよいか|スタンプ1個ごとに付与日から1年とする|
|支払い前にキャンセルされた場合はスタンプを付与せず、支払い後にキャンセルされた場合は付与済みスタンプを取り消す、という理解でよいか|その理解で良い|
|スタンプカードはアプリのどの画面に見れますか|スタンプの専用画面で見れます|
|10個貯まった際は古い順に10個を消費（FIFO）し、無料クーポンを自動発行する。クーポンの有効期限は無期限、発行枚数の上限もなし、という理解でよいか|その理解で良い|
|クーポンは値段に関係なく、どれでもいいのか|なんでもいいです|


## 業務フロー
```
[会員]
 1. アプリを開き、ログインする
 2. スタンプ専用画面で、有効なスタンプ数を確認する
 3. 未使用クーポンがあれば、次の注文で使用するか選ぶ
 4. 支払いを行う

[システム]
 5. 支払いが確定したら、新しいスタンプを1個付与する
 6. 有効なスタンプ数が10個に達した場合、古い順に10個を消費済みとして記録し、
    無料クーポンを1枚発行する

[例外・ルール]
 - 支払い前にキャンセルされた場合、スタンプは付与されない
 - 支払い後にキャンセルされた場合、付与済みのスタンプは取り消される
 - 有効なスタンプ数は保存せず、表示のたびに数え上げる
 - 有効期限（付与日から1年）を過ぎたスタンプは、保有数から除外される
 - 消費済みスタンプは失効の対象外
 - クーポンの発行枚数に上限はなく、条件を満たすたびに発行される
 - クーポンに有効期限はない
 - スタンプは店舗をまたいで共通に加算される
```
