# 問題1：スタンプカード（ポイント） — 要件定義

## 受け取った要求

「注文1回につきスタンプを1個押したい。
10個たまったら、次の注文でハンバーガー1つが無料になる。
スタンプは店舗をまたいで共通。有効期限は最後の注文から1年。
お客さんは、いま何個たまっているかをアプリで見たい。」

## 確認したいこと（質問リスト）

| 質問 | 今回の回答（仮） |
|---|---|
| 有効期限は「スタンプ」ではなく「クーポン」に持たせることでよいか。つまりスタンプは失効せず、10 個たまって発行されたクーポンに期限を設ける形でよいか | クーポンに期限を持たせる。スタンプは失効しない |
| 特典は「ハンバーガー1つ無料」ではなく「600 円引き」などの割引券とすることでよいか。将来「ドリンク無料」「500 円引き」など別の特典を出すときに、同じ仕組みで扱えるようにするため。これでよいか | 600 円の割引券とする。単品バーガーはこの額に収まる想定 |
| 割引額が注文の合計を超えた場合、超過分はどう扱うか（切り捨てる／次回に繰り越す／そもそも使えない） | 切り捨てる。繰り越さない |
| スタンプを付与するのは「支払いが完了したとき」か「商品を受け渡したとき」か。受け渡していない注文（未受け取り）にもスタンプを付けるか | **受け渡しが完了したとき**に付与する。未受け取りの注文にはスタンプを付けない |
| スタンプ 10 個以外の理由でクーポンを発行することはあるか（誕生日、キャンペーンなど） | ある想定。スタンプ 0 個でも発行できる仕組みにしておく |
| クーポンの有効期限は一律で決めるか、発行のたびに決めるか | 発行のたびに決める。スタンプ由来は発行から 1 年とする |

## 業務フロー

```
[会員]
 1. アプリを開き、ログインする
 2. スタンプ数と、持っているクーポンを確認する
 3. 未使用のクーポンがあれば、次の注文で使用するか選ぶ
 4. 注文し、支払う
 5. 店舗で商品を受け取る

[システム]
 6. 受け渡しが完了したら、スタンプを 1 個付与する
 7. 未消費のスタンプが 10 個に達したら、古い順に 10 個を消費し、クーポンを 1 枚発行する

[例外・ルール]
 - 受け渡しが完了していない注文には、スタンプを付与しない
   （キャンセルされた注文・未受け取りの注文はどちらも対象外）
 - スタンプは失効しない
 - クーポンには有効期限があり、期限を過ぎたものは使えない
 - クーポンの割引額が注文の合計を超えた場合、超過分は切り捨てる
 - 1 注文で使えるクーポンは 1 枚まで
 - クーポンの発行枚数に上限はない
 - スタンプ 0 個でもクーポンを発行できる（誕生日・キャンペーンなど）
 - スタンプは店舗をまたいで共通に加算される
```
