# 問題1：スタンプカード（ポイント） — 要件定義

## 受け取った要求

「注文1回につきスタンプを1個押したい。
10個たまったら、次の注文でハンバーガー1つが無料になる。
スタンプは店舗をまたいで共通。有効期限は最初のスタンプでカードを作成してから1年。
お客さんは、いま何個たまっているかをアプリで見たい。」

## 確認したいこと（質問リスト）

| 質問 | 今回の回答（仮） |
|---|---|
| クーポンの種類（対象商品・必要スタンプ数・有効日数・配布期間）を本部が登録・管理できるようにしたい。「バーガー無料券」「誕生日ドリンク券」などを、コードを変えずに増やせるようにするため。これでよいか | マスタとして管理する。本部が登録する |
| クーポンをいつからいつまで配るかを、登録時に決められるようにしたいか。開始日が来る前は会員から見えない状態で先に登録しておきたいか | 配布期間を持たせる。開始日が来るまでは「準備中」とし、期日が来たら自動で配布中に切り替える。将来のキャンペーンを先に登録できる |
| 配った後に期限を切らないクーポン（誕生日クーポンなど）を運用する可能性があるか | ある。有効日数を持たないクーポンを許す。その場合、配られた会員クーポンは期限切れにならない |
| スタンプを付与するのは「支払いが完了したとき」か「商品を受け渡したとき」か。受け渡していない注文（未受け取り）にもスタンプを付けるか | **受け渡しが完了したとき**に付与する。未受け取りの注文にはスタンプを付けない |
| 有効期限は「スタンプ 1 個ごと」ではなく「貯めているカード 1 枚ごと」に持たせたい。1 個目のスタンプが押された日から数えて 1 年、という理解でよいか | カード 1 枚ごとに持たせる。スタンプ単体は失効しない |
| 特典は「その商品が無料」だけか。「その商品が◯◯円引き」も出す想定があるか | 両方出せるようにする。割引額を持たない場合は「無料」とする |
| スタンプを貯めている途中のカードは、会員あたり同時に何枚まで持てるか | 1 枚まで。1 回の受け渡しで押されるスタンプは 1 個 |

## 業務フロー

```
[会員]
 1. アプリを開き、ログインする
 2. 貯めているスタンプ数と、使えるクーポンを確認する
 3. 使えるクーポンがあれば、次の注文で使用するか選ぶ
 4. 注文し、支払う
 5. 店舗で商品を受け取る

[システム]
 6. 受け渡しが完了したら、スタンプを 1 個押す
    貯めているカードが無ければ、配布中のクーポンから新しいカードを作る
 7. スタンプが必要数に達したら、そのカードを使用可能にする

[本部]
 8. クーポンの種類（対象商品・必要スタンプ数・有効日数・配布期間）を登録する
    開始日より前に登録しておける。その間は「準備中」で、会員には見えない
 9. 準備中のうちは配布期間を書き換えられる。配布中に入った後は終了日だけ変えられる
    当日中に止めたい・始めたい場合は、配布期間と状態を同時に書き換える

[システム]
 10. 開始日が来たクーポンを配布中に、終了日を過ぎたクーポンを配布終了に切り替える

[例外・ルール]
 - 受け渡しが完了していない注文には、スタンプを押さない
   （キャンセルされた注文・未受け取りの注文はどちらも対象外）
 - スタンプ単体は失効しない。有効期限はカード 1 枚ごとに持つ
 - 有効期限を過ぎたカードは使えなくなり、押されたスタンプは削除される
   （カードの行は、使われずに終わった枚数を数えるために残す）
 - 有効日数を持たないクーポンから配られたカードは、期限切れにならない
 - 新しいカードの貯め先になるのは、配布中かつ配布期間内で、必要スタンプ数が 1 以上のクーポンだけ
   準備中・配布終了のクーポン、必要スタンプ数 0 のクーポンは貯め先に選ばれない
 - 対象メニューが販売終了になった場合、そのクーポンは配布終了にし、貯め中・使用可能の会員クーポンも無効化する
   （無効化したカードのスタンプは、期限切れと同じく削除する）
 - スタンプを貯めているカードは、会員あたり同時に 1 枚まで
 - 使えるクーポンは、未使用のまま複数枚持てる
 - 1 注文で使えるクーポンは 1 枚まで
 - 対象商品が注文に複数個あっても、割引は 1 個分だけ。オプションの加算分は割引の対象外
 - クーポンは注文が確定した時点で使用済みになる
   注文がキャンセルされたら使える状態に戻す。未受け取りで終わった場合は戻さない
 - 割引額が対象商品の価格を超えた場合、超過分は切り捨てる
 - 通常の配布終了にしても、すでに配られたクーポンは有効期限まで使える
 - 必要スタンプ数が 0 のクーポンは、スタンプを貯めずに配れる（誕生日など）
 - 必要スタンプ数が 1 以上のクーポンは、配布中の期間が重ならないように登録する
   （同時に 2 つあると、スタンプを貯める先が決まらない）
 - スタンプは店舗をまたいで共通に加算される
```
