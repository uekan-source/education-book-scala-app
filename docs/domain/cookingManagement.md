# 問題2：店舗スタッフ向けの調理管理

## 1. 業務フロー（主語つき・例外つき)

[会員]
 1. アプリを開き、ログインする
 2. 受け取る店舗を選ぶ（営業時間外の店は選べない）
 3. メニューを見る（カテゴリごとに商品が並ぶ／売り切れの商品は選べない）
 4. 商品を選ぶ
 5. オプションを選ぶ（サイズは 1 つだけ、トッピングは複数可、必須のものもある）
 6. 数量を決めてカートに入れる
 7. カートの中身と合計金額を確認する（何度でも足したり消したりできる）
 8. 受け取り時間を選ぶ
 9. 注文を確定する  ← ここで金額が確定する
10. 支払う（外部の決済サービスへ）
11. 注文の状態を見ながら待つ
12. 店舗で受付番号を見せて、商品を受け取る

[店舗スタッフ]
13. 入った注文を見る
14. 調理を始める        ← ここから会員はキャンセルできない
15. できあがったら「受け取り準備完了」にする
16. 会員に渡して「受け渡し完了」にする

[例外・ルール]
 - 売り切れの商品はカートに入れられない／注文確定時にも再チェックする
 - 営業時間外の店舗には注文できない
 - 調理開始後はキャンセルできない
 - 注文したあとに商品の価格が変わっても、注文の金額は変わらない
 - 商品が販売終了になっても、過去の注文履歴は正しく表示できる


 ## ② 名詞と動詞を拾う

 **名詞**：会員、店舗、営業時間、メニュー、カテゴリ、商品、価格、オプション、
           サイズ、トッピング、セット、売り切れ、カート、数量、合計金額、
           受け取り時間、注文、受付番号、注文明細、支払い、決済サービス、
           注文の状態、調理

**動詞**：ログインする、選ぶ、（カートに）入れる、消す、確認する、確定する、
          支払う、（状態を）見る、調理する、（準備）完了にする、受け渡す、
          キャンセルする、（売り切れを）チェックする、（金額を）計算する


## ③ 名詞をふるいにかける

| 名詞 | 仕分け | 理由 |
|---|---|---|
| 会員 | **エンティティ** | ID で区別する。雛形の `User` をそのまま使う |
| 店舗 | **エンティティ** | 複数あり、それぞれ独立して管理される |
| 営業時間 | 属性 | 店舗の一部（開店時刻・閉店時刻） |
| カテゴリ | **エンティティ** | 表示順を持ち、本部が管理する。商品がぶら下がる |
| 商品 | **エンティティ** | 価格改定や販売終了があり、履歴を追う必要がある |
| 価格 | **値オブジェクト** | 590 円は 590 円。区別する意味がない |
| オプション（サイズ / トッピング） | **エンティティ** | 「選択肢のまとまり」と「1 つの選択肢」の 2 階層。商品から参照される |
| セット | 対象外（＝商品の一種） | 「セット」も 1 つの商品として扱い、中身の選択はオプションで表現する |
| 売り切れ | 属性 | ただし **店舗ごとに違う** ので、店舗と商品の組に対する状態になる |
| カート | **エンティティ** | 会員ごとに 1 つあり、中身が変わる |
| 数量 | **値オブジェクト** | 2 個は 2 個 |
| 合計金額 | 属性（ただし注文では保存する） | → [設計上の論点](#設計上の論点とその判断) で扱う |
| 受け取り時間 | 属性 | 注文の一部 |
| 注文 | **エンティティ** | 業務の中心。ID で追跡し、履歴として残す |
| 受付番号 | 属性（値オブジェクト） | 注文の公開用識別子。連番の ID は晒さない |
| 注文明細 | **エンティティ** | 1 注文に複数。1 行ごとに商品・数量・価格を持つ |
| 支払い | **エンティティ** | 外部サービスの取引 ID と結果を記録し、追跡する |
| 決済サービス | 対象外 | 外部システム。こちらのモデルではない |
| 注文の状態 | 属性（`EnumStatus`） | 注文の一部。遷移する |
| 調理 | 対象外（＝状態遷移） | 「調理中」という状態として表現する |


## ④ 用語をそろえる（ユビキタス言語）

| 日本語 | 英語名 | 意味 | 備考 |
|---|---|---|---|
| 会員 | `User` | サービスの利用者 | 雛形の `edu.udb` をそのまま使う |
| 店舗 | `Shop` | 商品を受け取る実店舗 | 営業時間を持つ |
| メニューカテゴリ | `MenuCategory` | バーガー / サイド / ドリンクなどの区分 | 表示順を持つ |
| 商品 | `MenuItem` | 販売する 1 品目 | 「メニュー」「品目」はこれに統一 |
| オプショングループ | `MenuOptionGroup` | 選択肢のまとまり（サイズ / トッピング） | 単一選択か複数選択か、必須かを持つ |
| オプション項目 | `MenuOptionItem` | 選択肢 1 つ（M サイズ / ピクルス抜き / パティ追加） | 追加料金を持つ |
| 商品のオプション | `MenuItemOptionGroup` | 商品にどのオプショングループが付くか（多対多） | 商品ごとの表示順を持つ |
| 取扱状況 | `ShopMenuStock` | 店舗 × 商品の組。売り切れをここで持つ | |
| カート | `Cart` | 注文確定前の下書き | 「買い物かご」はこれ |
| カート明細 | `CartItem` | カートに入れた 1 行 | |
| カート明細のオプション | `CartItemOption` | カート明細に付けた選択肢 | |
| 注文 | `Order` | 確定した注文 | 「オーダー」「受注」はこれに統一 |
| 注文明細 | `OrderItem` | 注文の 1 行 | |
| 注文明細のオプション | `OrderItemOption` | 注文明細に付いた選択肢 | |
| 受付番号 | `Order.Code` | 店頭で呼び出すための番号 | 会員に見せる ID |
| 支払い | `Payment` | 決済の記録 | |
| 金額 | `Money` | 日本円（1 円単位） | 値オブジェクト |
| 数量 | `Quantity` | 個数（1〜99） | 値オブジェクト |


## ⑤ 境界を引く（コンテキス

| コンテキスト | 記号 | 変更の理由 | ライフサイクル | 管理する人 |
|---|---|---|---|---|
| 会員 | `udb` | 認証方式の変更 | 数年 | 会員本人 |
| 商品マスタ | `common/menu` | メニュー改定・価格改定 | 数ヶ月〜数年 | 本部 |
| 店舗 | `shop` | 新店舗・営業時間の変更・**売り切れ** | 店舗は数年、売り切れは **数時間** | 本部（店舗）／店長（売り切れ） |
| 注文 | `sales` | 注文フローの変更・決済手段の追加 | 数十分（履歴としては永久） | 会員と店舗スタッフ |
